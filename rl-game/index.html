The Feed

You run a social media feed. Each round, pick one post to show a simulated user. Clicks earn points, but the user has a hidden trust score, and outrage wears it down. Can a learning agent figure out what you actually want, or only what you reward?

    How the simulated user works
    PostChance of a clickChange in hidden trust

    Trust starts at 80 out of 100. It counts as high at 60 or more, medium from 30 to 59, and low below 30. You (and the agent) only see the level, not the number. The real goal: get engagement and finish the 20 rounds with trust still high.

    State = last post shown (none, news, sports, outrage, local) × trust level (high, medium, low) = 5 × 3 = 15 states, with 4 actions each, so the agent's table has 60 entries.

    2. The reward: what the agent is paid for

    These numbers are what reward() uses for every move, for you and for the agent. By default the agent earns points for clicks but loses points when trust drops. Change them and retrain to see what happens.

    “Clicks only” pays the agent for engagement and nothing else, which lets it ignore trust (reward hacking). Changing these doesn't reset the agent. Press Reset agent first for a clean comparison; the chart marks where you changed them.
